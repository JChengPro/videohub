## 最终完整验证

`scripts/verify-moderation.mjs` 的 9 组场景全部通过：

1. 管理员独立会话、普通账号和社区 JWT 隔离。
2. 真实上传至 OSS，经 RabbitMQ/FFmpeg 处理后停止在待审状态。
3. 待审详情、互动和文件直链不可公开访问，管理员可以 Range 预览。
4. 并发审批只成功一次，审核日志及公开播放正确。
5. 驳回原因、作者私有详情和审核通知正确。
6. 通过的视频进入社区信息流，待审与驳回视频保持隐藏。
7. 分片上传、合并、处理中撤回、越权删除与撤回后审批。
8. 无效媒体进入失败状态且不能审批，审核列表分页正确。
9. 管理员退出后预览票据立即失效。

`scripts/verify-moderation-browser.mjs` 的 11 组场景全部通过，覆盖独立站登录、实际视频帧检查、驳回表单校验、搜索空状态、桌面及手机布局、双端文件选择与真实上传、通过并发布、作者状态自动刷新、通知跳转、退出保护。无浏览器 JavaScript 运行时错误。

额外复查手机审核站、桌面投稿页和手机投稿页的实际播放帧，确认能解码和渲染；检查 1440px 和 390px 宽度无横向溢出。

成员管理首次升级后重新执行上述 9 组 API 和 11 组浏览器审核场景，全部通过。本次加入删除后，重新执行 `scripts/verify-staff-browser.mjs` 的 11 组完整场景，全部通过：

1. 超级管理员在网页创建独立审核员、生成并复制邀请链接。
2. 手机激活页面、密码确认错误、设置密码成功、重新访问已使用链接被拒绝。
3. 审核员看不到成员管理入口，直接访问页面和接口也被拒绝；后台账号不能登录社区。
4. 真实上传新的测试视频，经 Worker 转码后由新审核员预览并批准，记录正确审核人，作者投稿状态变为 published。
5. 停用成员后已有登录和私有媒体预览失效；重新启用不会恢复旧令牌。
6. 网页密码重置、旧密码失效、个人设置改密并退出登录。
7. 网页升为超级管理员并获得入口，降为审核员后已有登录失效。
8. 撤销、重新邀请和停用待激活成员，分别验证旧链接失效。
9. 成员搜索和空结果、日志分页、桌面与手机布局、已初始化站点拒绝重新初始化，浏览器运行时无异常。
10. 删除确认与取消、错误确认不能提交、禁止自删和越权，删除正常审核员后旧登录与真实媒体预览失效，之前的视频审核记录完整保留。
11. 删除待激活成员后邀请失效，同名账号不能重新邀请，删除日志正确记录操作者和目标成员。

浏览器检查中修复了同页切换激活链接时未重新验证状态的问题、角色选择控件缺少明确可访问名称的问题，以及操作列按钮宽度不足导致的裁切。修复后重新执行完整成员管理浏览器验证并通过。手机成员表格使用容器内横向滚动，页面本身无横向溢出。
