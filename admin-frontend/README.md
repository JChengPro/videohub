# VideoHub 独立审核网站

独立 Vue 3 / TypeScript 应用。与桌面社区、手机社区分别构建和部署，通过现有 Go API 的 `/admin/*` 接口处理审核。

## 启动

在项目根目录运行：

```bash
docker compose up -d --build backend worker frontend mobile-frontend admin-frontend
```

- 审核站：`http://localhost:5176`
- 桌面社区：`http://localhost:5173`
- 手机社区：`http://localhost:5174`

可用 `ADMIN_PORT` 修改审核站映射端口。生产 Compose 默认只将审核端口绑定到 `127.0.0.1`，由独立域名的 HTTPS 反向代理转发；审核站不参与社区的设备分流。

前端开发：

```bash
cd admin-frontend
npm ci
npm run dev
```

Vite 默认端口为 5175，代理至本机 8080 API；端口占用时会选择下一可用端口。

## 添加与管理人员

使用超级管理员账号登录，打开 **成员管理 → 添加成员**，填写姓名、登录账号并选择角色，点击 **生成邀请**。复制链接，通过内部沟通渠道发给对应同事。对方打开链接设置自己的密码后即可登录，不需要社区账号，也不需要执行命令。

- 姓名为 1 至 24 字；登录账号为 3 至 64 位字母、数字或 `. _ @ + -`，统一转为小写。
- 新密码至少 12 字符、最多 72 字节，首尾不能有空格。系统不展示已有密码。
- **审核员**可以查看和处理视频；**超级管理员**还可邀请成员、调整角色、停用或启用、重置密码、查看操作日志。
- 邀请链接和重置链接均为 24 小时有效、一次性使用。可以撤销或重新生成；重新生成后旧链接失效。
- 待激活成员必须接受邀请才能登录。被停用的待激活成员重新启用后，需重新生成邀请。
- 修改角色、停用成员会使该成员现有会话和未使用链接失效；最后一个正常的超级管理员不能被停用或降级。
- 永久移除人员时，点击成员行的垃圾桶图标，输入目标登录账号并点击 **确认删除**。支持删除正常、停用和待激活成员；不能删除自己或最后一位正常的超级管理员。
- 删除后人员从列表移除，密码摘要、后台登录、邀请和重置链接被清除，历史审核和操作日志仍保留。无法通过启用或运维恢复撤销删除，登录账号不能复用；暂时禁用人员应使用“停用”。
- 忘记密码时，超级管理员在成员行点击钥匙图标生成重置链接。成员也可在 **个人设置** 使用原密码自行修改密码；成功后需要重新登录。
- 当前没有自动邮件发送，链接由管理员复制交付；自动复制不可用时可选中链接手动复制。

成员列表可搜索、按状态筛选和分页，展示最近登录、添加人和邀请状态。删除当前分页最后一条后会自动回到有效页面。**操作日志**记录添加、激活、角色／状态变更、删除、链接撤销和密码操作，不保存明文密码或完整链接。

## 首次安装与升级

**已有审核管理员的升级部署**：首次启动自动将旧管理员迁移为独立后台超级管理员，原账号密码可继续使用。旧审核会话会清除，请重新登录。迁移仅执行一次；之后社区账号及其密码、角色不会影响后台人员。

**全新安装**由部署负责人完成一次配置：

1. 在部署环境设置 `ADMIN_SETUP_TOKEN` 为至少 32 位随机安装凭证，例如使用 `openssl rand -hex 32` 生成，并重新创建 backend 容器。
2. 管理负责人访问审核站 `/setup`，填写安装凭证、姓名、登录账号和密码，创建首位超级管理员。
3. 创建完成后初始化自动关闭。可从部署环境移除安装凭证，再重新创建 backend 容器。

没有有效安装凭证时不能注册后台账号。已存在任何后台成员时，初始化接口不能再次创建管理员；并发初始化也只能成功一次。普通管理人员后续均使用网页管理成员。

后台会话有效期为 8 小时，每次请求检查账号状态、角色、有效期和密码指纹。后台账号与社区账号分别保存密码；社区改密不会更改后台密码。

仅在运维恢复时，可用 `docker compose exec backend /app/admin -account 已激活的后台账号` 恢复该成员的超级管理员权限，或追加 `-revoke` 停用。工具仅处理已存在且激活的后台成员，保留最后一个管理员保护并记录操作日志，不再把社区用户直接提升为后台人员。

## 审核范围

待审核、已发布、已驳回、处理中、处理失败和已撤回列表支持搜索、分页和详情。管理员查看视频、封面、标题和简介后通过或驳回；驳回原因必填，审核历史记录审核人和时间。历史已发布视频保持公开，没有伪造的审核记录。

提交后的封面和视频不可修改。被驳回的作者可查看原因、撤回并重新投稿。暂不提供批量审批、多级审核、申诉和已发布作品下架。

技术说明及验证步骤见 [审核模块文档](../docs/moderation.md)。
